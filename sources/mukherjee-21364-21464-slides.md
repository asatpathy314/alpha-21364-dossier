# Mukherjee, The Alpha 21364 and 21464 Microprocessors (Compaq slides)

Shubhendu Mukherjee’s roadmap talk places the 21364 between the 21264 and the cancelled 21464 (EV8), and summarizes what each generation added. It is useful for the overview slides and for the “what came next” discussion.

[Slides at WikiChip](https://en.wikichip.org/w/images/6/6d/alpha_21464.pdf) · [Partial excerpt on a Nanjing University course page](https://cs.nju.edu.cn/swang/CA_16S/Lec16_Alpha21464.pdf).

**Secondary source. Vendor presentation. The WikiChip PDF could not be reached when this dossier was built (connection refused), so only the 15-slide course excerpt was read. Re-check the first link before citing slide numbers.** The full title is “The Alpha 21364 and 21464 Microprocessors: Continuing the Performance Lead Beyond Y2K,” Compaq Alpha Development Group, about 2000–2001.

## Where to look

- **Roadmap.** The excerpt’s opening slides place the 21264, 21364 and 21464 at 0.35, 0.18 and 0.125 µm across 1998–2003.
- **21364 summary.** In the full deck, the 21364 slides repeat the feature list from [Bannon’s 1998 talk](bannon-21364-microprocessor-forum-1998.md): the 21264 core, on-chip L2, memory controllers and router.
- **21464.** The excerpt covers the EV8 design: a large on-chip L2 and four-way simultaneous multithreading.
