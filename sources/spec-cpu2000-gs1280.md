# SPEC CPU2000 results for the AlphaServer GS1280

SPEC’s published results are an independent, third-party record of the chip’s benchmark performance, with the tested configuration spelled out. The 2004 results for the 1300 MHz part are the final ones for the 21364; the 2003 results for the 1150 MHz part match the configuration in the Cvetanovic papers.

[SPECint2000, GS1280 7/1300](https://www.spec.org/cpu2000/results/res2004q3/cpu2000-20040622-03150.html) · [SPECfp2000, GS1280 7/1300](https://www.spec.org/cpu2000/results/res2004q3/cpu2000-20040622-03148.html) · [All CINT2000 results](https://www.spec.org/cpu2000/results/cint2000.html) · [All CFP2000 results](https://www.spec.org/cpu2000/results/cfp2000.html).

**Primary source. Published benchmark result (tested and submitted by HP, audited by SPEC). Open.** Test date June 2004; hardware available August 2004.

## Where to look

- **Configuration block.** Every result page lists the processor, the 64 KB + 64 KB L1, the 1.75 MB on-chip L2 per CPU, the memory per CPU, the operating system and the compilers.
- **Single-processor scores, 7/1300.** SPECint2000 994 (base 904); SPECfp2000 1684 (base 1279).
- **Rate results, 7/1300.** SPECint_rate2000 runs from 11.5 at one processor to 728 at 64; SPECfp_rate2000 from 19.6 to 1224. Search the rate index pages for “GS1280” to find each row.
- **Single-processor scores, 7/1150 (2003).** SPECint2000 877 (base 795), result 20030113-01918; SPECfp2000 1482 (base 1124), result 20030113-01917.
- **Independent bandwidth figures.** The [STREAM benchmark site](stream-benchmark.md) lists HP’s GS1280 submissions separately.
